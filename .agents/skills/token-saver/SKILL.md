# Token Saver

This is an original, instruction-only skill. It does not change model settings, limits, billing, permissions or context size and promises no fixed saving percentage.

- Locate relevant files and symbols with bounded searches before reading. Read changed ranges and avoid rereading unchanged content already in context.
- Keep verbose logs, full scene inventories and generated data on disk. Return counts, selected errors, artifact paths and relevant object summaries; expand only when needed to resolve uncertainty.
- For Blender query names, types, counts and bounding boxes before requesting detailed geometry. Never print vertex arrays, binary files, image base64 or credentials.
- Keep a compact HANDOFF.md for long work: objective, verified state, important paths, decisions, unresolved errors and next action. Replace stale details instead of appending every operation.
- Load only the skill references needed for the active route. Preserve source links and exact errors needed for verification. Token savings must not replace required validation or conceal failed checks.
- Batch independent reads when useful. Do not repeatedly poll unchanged cloud status; inspect on completion, failure or a meaningful transition. Report actual results concisely.

Assessment sources: https://github.com/ryohgicc/token-saver-skill and https://github.com/thinkofuture/TokenSaver . Their workflows were evaluated, but no third-party text or executable hooks are bundled. No explicit license file was found in the reviewed ryohgicc checkout, so this package uses its own instructions.
